# Политика безопасности

Keramika — приложение с открытым исходным кодом. Мы воспринимаем безопасность
ваших данных серьёзно.

## Поддерживаемые версии

Поддерживается только последний стабильный релиз в
[Releases](https://github.com/wxstdo-boop/Keramika/releases). Старые версии не
получают патчей безопасности — обновитесь через автообновление в приложении.

## Сообщение об уязвимости

Если вы нашли уязвимость, пожалуйста, не публикуйте её открыто. Напишите
maintainer'у напрямую через [GitHub Issues](https://github.com/wxstdo-boop/Keramika/issues/new)
с пометкой «Security» или на электронную почту, указанную в профиле репозитория.

Включите:
- версию приложения (`v<имя>+<код>` из pubspec.yaml),
- модель телефона и версию Android,
- шаги для воспроизведения,
- скриншот или логи, если применимо.

Мы подтвердим получение в течение 7 дней и сообщим о плане исправления.

## Что мы делаем для безопасности

- **Нет бэкенда.** Приложение не отправляет ваши данные ни на какие свои серверы.
  Единственные сетевые запросы — к GitHub (проверка обновлений) и к выбранному
  пользователем ИИ-провайдеру (ключ хранится только на устройстве).
- **HTTP запрещён.** `android:usesCleartextTraffic="false"` +
  `network_security_config` — весь трафик только по HTTPS.
- **Никаких ключей в репозитории.** `keystore.jks`, `key.properties`, секреты
  GitHub Actions — всё вне репозитория, в `.gitignore` и encrypted secrets.
- **Релизы подписаны.** Keystore восстанавливается из зашифрованных секретов
  репозитория при сборке через GitHub Actions (`release.yml`, `ship.yml`).
- **Резервные копии отключены.** `allowBackup="false"` +
  `data-extraction-rules` с `no-backup` — ваши данные не извлекаются при переносе
  на новое устройство.
- **PIN-хранилище шифруется.** Данные приложения шифруются AES-256-GCM через
  `JsonFile` с ключом в `EncryptedSharedPreferences` (Keystore Android).

# Скриншоты

Здесь лежат настоящие скриншоты приложения — с демо-данными, без отладочного
мусора и личных записей. Их не снимают руками: их **генерирует тест**, поэтому
набор воспроизводим и всегда совпадает с текущим видом приложения.

## Что есть

| Файл | Что на нём |
|---|---|
| `alarms.png` | Список будильников |
| `habits.png` | Привычки со стриками |
| `tasks.png` | Задачи с приоритетами |
| `stats.png` | Статистика РП |

## Как сгенерировать

Скрипт монтирует реальные экраны в настоящей теме
(`lib/theme/app_theme.dart`) и рендерит их в PNG:

```bash
flutter test tool/screenshots/render_screenshots.dart
```

Файлы кладутся в `docs/screenshots/`. Скрипт лежит вне `test/`, поэтому
обычный `flutter test` его не подхватывает.

Нужен настоящий шрифт с кириллицей: в тестовой среде Flutter подставляет
заглушку «квадратики». Скрипт сам подгружает системный Roboto из pub-кэша
(или DejaVu Sans), поэтому в CI/песочнице ничего доустанавливать не нужно.

## Правила

- **Никаких личных данных.** Только демо-записи из `_seed()` в скрипте.
- Одна тема и один размер на всю галерею (сейчас светлая, 1080×2280 @3x).
- Имена файлов — строчные, как в таблице выше.

## Подключение к README

Галерея в корневом `README.md` ссылается на эти файлы. После регенерации
снимки обновляются автоматически — правки в README не нужны.

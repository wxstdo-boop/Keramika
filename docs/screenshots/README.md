# Скриншоты

Здесь должны лежать настоящие скриншоты приложения — с реальными данными,
без отладочного мусора и личных записей.

## Что снять

Минимум пять экранов, которые закрывают основные разделы:

| Файл | Что на нём |
|---|---|
| `alarms.png` | Список будильников |
| `habits.png` | Привычки со стриками |
| `tasks.png` | Задачи с приоритетами |
| `nutrition.png` | Питание с кольцами норм и трендами |
| `ada.png` | Диалог с Адой (желательно снять и оверлей поверх другого приложения) |
| `lock.png` | Экран ввода PIN |

## Как снять

На устройстве с тёмной темой и Material You — так скриншоты будут в одном
стиле с иконкой приложения.

```powershell
# Windows: отложенный скриншот с устройства
adb shell screencap -p /sdcard/shot.png
adb pull /sdcard/shot.png docs/screenshots/alarms.png
```

Либо просто `Win + Shift + S` на телефоне через scrcpy.

## Правила

- **Никаких личных данных.** Убери реальные заметки, имена и истории.
- **Без статус-бара с личным временем и уведомлениями** — обрезай сверху.
- Одна тема на всю галерею, иначе README выглядит собранным из разных дней.
- Имена файлов — строчные, через дефис, как в таблице выше.

## Подключение к README

Когда скриншоты готовы, замени таблицу с логотипами в
[README.md](../README.md) на реальные картинки и впиши alt-тексты:

```html
<div align="center">
  <table>
    <tr>
      <td width="33%"><img src="docs/screenshots/alarms.png" alt="Список будильников" /></td>

    </tr>
  </table>
</div>
```
